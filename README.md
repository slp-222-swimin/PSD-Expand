# 📦 PSD Layer Export Tool

Photoshop（PSD）ファイルのレイヤー構造を、そのままフォルダ＋PNG画像として書き出すシンプルなツールです。

---

## ✨ 概要

このツールは以下を自動で行います：

* PSDファイルを解析
* レイヤーグループをフォルダとして再現
* 各レイヤーをPNG画像として書き出し
* 非表示レイヤーはスキップ

---

## 🧠 出力イメージ

### 入力（PSD構造）

```
Root
├─ GroupA
│  ├─ Layer1
│  └─ Layer2
└─ Layer3
```

### 出力（フォルダ構造）

```
output/
├─ GroupA/
│  ├─ Layer1.png
│  └─ Layer2.png
└─ Layer3.png
```

---

## ⚙️ 必要環境

* Python 3.8+
* 必須ライブラリ：

```bash
pip install psd-tools
```

---

## 🚀 使い方

### ▶ 方法①：コマンドラインから実行

```bash
python script.py input.psd output_folder
```

---

### ▶ 方法②：対話形式で実行

```bash
python script.py
```

実行後、以下を入力：

* PSDファイルのパス
* 出力先フォルダ

---

## 📁 出力仕様

| 項目      | 内容          |
| ------- | ----------- |
| 画像形式    | PNG         |
| フォルダ構造  | PSDと同じ      |
| 非表示レイヤー | 出力しない       |
| ファイル名   | 使用不可文字は自動置換 |

---

## 🔒 ファイル名の安全化

以下の文字は自動的に `_` に置換されます：

```
\ / : * ? " < > |
```

---

## ⚠️ 注意事項

* 一部の特殊レイヤー（調整レイヤーなど）は正しく出力されない場合があります
* 同名レイヤーがある場合、ファイルが上書きされる可能性があります
* 非表示レイヤーのみのグループは空フォルダになることがあります
